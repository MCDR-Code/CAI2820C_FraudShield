# References across the project

update notes. Each phase keeps its own rubrics, instructor forms and specific
references in its References subfolder. Some supplied instructor documents remain
local rather than being republished.

See Architecture_and_Pipeline.md for the system/pipeline diagrams,
Data_and_Models.md for the shared local resources, and Reorganization.md for the
mapping from the previous folders.
